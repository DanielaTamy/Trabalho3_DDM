# Aplicativo de Grimório de Hogwarts

O aplicativo Android consulta a [Hogwarts API](https://hogwarts-api.com/) para buscar personagens e criaturas.

## Funcionalidades

- Menu principal com acesso às duas telas de busca.
- Busca de personagens por parte do nome, com exibição de nome, espécie e casa.
- Busca de criaturas pelo nome completo, com exibição de nome e imagem. Se a imagem estiver ausente ou falhar ao carregar, o app mostra uma imagem substituta e o aviso **Imagem indisponível**.
- Validação do campo de busca, indicador de carregamento e mensagens para consultas sem resultado ou com erro de conexão.
